## 0. Общие сведения

Ранее вам была прислана ссылка короткого формата. Её не нужно открывать в браузере. Нужно скопировать и вставить её в одно из клиентских приложений с поддержкой **XRay-core**, указанных в статье ниже.

> Если у вас возникают проблемы с установкой приложений из-за блокировок - я могу выслать файлы по почте. Напишите мне в личных сообщениях операционные системы и адрес вашей почты.

После импорта появятся два немецких сервера:

- **Whitelist** - обходит белые списки, но нагружает сеть и работает медленнее. Пожалуйста, используйте только когда это действительно нужно.
- **Main** - без обхода белых списков, зато быстрее и стабильнее. Предпочтителен при кабельном интернете.

## 1. Мобильные устройства (Android / iOS)

- **Android** - скачиваем [**v2RayTun**](https://play.google.com/store/apps/details?id=com.v2raytun.android&hl=en&pli=1) в Google Play, нажимаем «**+**» и импортируем ссылку из буфера обмена.
- **iOS** - скачиваем [**v2Box**](https://apps.apple.com/us/app/v2box-v2ray-client/id6446814690) в App Store, с v2RayTun на iOS есть проблемы.

> _Начиная с_ [_28 марта 2026 года_](https://www.currenttime.tv/a/apple-po-trebovaniyu-roskomnadzora-udalila-neskolko-vpn-klientov-iz-rossiyskogo-app-store/33718658.html) _в_ **_App Store_** _данные приложения можно скачать_ **_только_** _при смене региона или_ [_Apple ID_](https://www.iphones.ru/iNotes/kak-sozdat-zagranichnyy-apple-id-bez-bankovskoy-karty-s-rossiyskim-nomerom-telefona-samyy-aktualnyy-sposob-v-2024-godu-04-13-2024) _на нероссийский._

> _Я не рекомендую использовать приложение_ **_Happ_** _ни на одном из устройств - это очень нестабильное приложение. Если вы пользовались им до прочтения этой статьи, замените его на одно из списка._

## 2. ПК (Windows / Linux / macOS)

Скачиваем **v2rayN** версии 7.7.0 с GitHub ([https://github.com/2dust/v2rayN/releases/tag/7.7.0](https://github.com/2dust/v2rayN/releases/tag/7.7.0)) и соответствующий .zip файл под свою OS. Обновляться до новых версий не рекомендуется.

> Если у вас Linux или macOS, обязательно посмотрите примечание в [п2.2](#22-примечания-для-пользователей-linux--macos) данной статьи

- Распаковываем архив, кликаем по главному файлу v2rayN **от имени администратора**. В папке ПКМ и создаём ярлык на рабочем столе, закрепляем на таскбаре для удобства.
- Запускаем главный файл v2rayN от имени администратора.
- Язык меняется через троеточие в правом верхнем углу.

![](https://s1.hostingkartinok.com/uploads/images/2026/03/a62bc6eef86e4589b11b1c7af859b184.jpg)

- Внизу выбираем «**Global**» и «**Установить системный прокси**».

![](https://s1.hostingkartinok.com/uploads/images/2026/03/fefa006ecb2f2a81437ffa0fe9269bb1.jpg)

- Чтобы вставить ссылку - переходим в раздел «**Серверы**» → «**Импорт по URL**». После этого сверху появляется окно «**import_sub**» рядом с «**Все серверы**» - переключаемся на него. Сверху нажимаем «**Группа подписки**» → «**Обновить подписку с прокси**».

![](https://s1.hostingkartinok.com/uploads/images/2026/03/8e4fcaa1ada2ab986acb3f4ef1260a12.jpg)

- Дважды кликаем по нужному серверу → «**Подтвердить**». VPN подключён и уже работает.

> ⚠️ Выключать VPN - не просто закрыть окно!! Нужно открыть скрытые иконки в трее, нажать на v2rayN и выбрать «**Выход**».

![](https://s1.hostingkartinok.com/uploads/images/2026/03/0d8043654774ea06b2a9115687099216.jpg)

В дальнейшем VPN включается автоматически при каждом запуске приложения.

Кнопка «**Режим VPN**» / «**VPN tun**» - это не включение VPN. Эта кнопка активирует режим туннелирования - нужна только если какие-то сайты или приложения не работают через обычный прокси. Я рекомендую всегда её включать.

### 2.1. Продвинутые настройки

Для улучшения скорости и работы VPN нужно перейти сверху в раздел _«_**_Настройки_**_»_ → _«_**_Настройка параметров_**_»_:

- → _«_**_Настройки TunMode_**_»_ → _включить поддержку IPv6._

> Даже если ваш **домашний** провайдер не поддерживает IPv6 - это нужно для другого.

- → _«_**_Ядро: базовые настройки_**_», включаем поддержку_ **_QUIC_**_._
- → _«_**настройки v2rayN**_»: Включить автозапуск (при включении ПК); включить протокол безопасности TLS v1.3; включить аппаратное ускорение._

### 2.2. Примечания для пользователей Linux / macOS

- Перед запуском приложения на Linux нужно поставить корректную версию ядра **sing-box** ([https://github.com/SagerNet/sing-box/releases/tag/v1.10.7](https://github.com/SagerNet/sing-box/releases/tag/v1.10.7)) и обновить **xray** до последней версии ([https://github.com/XTLS/Xray-core/releases](https://github.com/XTLS/Xray-core/releases)). Скачаются архивы с файлами sing-box и xray - их нужно переместить в папки «**v2rayN/bin/sing-box/**» и «**v2rayN/bin/xray/**» соответственно.

> Неизвестно, есть ли эта проблема на macOS - если возникает, пожалуйста, напишите мне.

- На macOS при открытии файла v2rayN есть проблема - нужно открыть командную строку и написать `xattr -cr путь-до-папки-v2rayN`, тогда предупреждение исчезнет.
