## 0. Общие сведения

Ранее вам была прислана ссылка короткого формата. Её не нужно открывать в браузере. Нужно скопировать и вставить её в одно из клиентских приложений с поддержкой **XRay-core**, указанных в статье ниже.

> Если у вас возникают проблемы с установкой приложений из-за блокировок — я могу выслать файлы по почте. Напишите мне в личных сообщениях операционные системы и адрес вашей почты.

## 1. Мобильные устройства (Android / iOS)

- **Android** — скачиваем [**v2RayTun**](https://play.google.com/store/apps/details?id=com.v2raytun.android&hl=en&pli=1) в Google Play, нажимаем <kbd>+</kbd> и импортируем ссылку из буфера обмена.
- **iOS** — скачиваем [**v2Box**](https://apps.apple.com/us/app/v2box-v2ray-client/id6446814690) в App Store, с v2RayTun на iOS есть проблемы.

> Начиная с [28 марта 2026 года](https://www.currenttime.tv/a/apple-po-trebovaniyu-roskomnadzora-udalila-neskolko-vpn-klientov-iz-rossiyskogo-app-store/33718658.html) в **App Store** данные приложения можно скачать **только** при смене региона или [Apple ID](https://www.iphones.ru/iNotes/kak-sozdat-zagranichnyy-apple-id-bez-bankovskoy-karty-s-rossiyskim-nomerom-telefona-samyy-aktualnyy-sposob-v-2024-godu-04-13-2024) на нероссийский.

> Я не рекомендую использовать приложение **Happ** ни на одном из устройств — это очень нестабильное приложение. Если вы пользовались им до прочтения этой статьи, замените его на одно из списка.

## 2. ПК (Windows / Linux / macOS)

Скачиваем **v2rayN** версии 7.7.0 с GitHub ([releases/tag/7.7.0](https://github.com/2dust/v2rayN/releases/tag/7.7.0)) и соответствующий `.zip` файл под свою OS. Обновляться до новых версий не рекомендуется.

> Если у вас Linux или macOS, обязательно посмотрите примечание в [п. 2.2](#22-примечания-для-пользователей-linux--macos) данной статьи.

1. Распаковываем архив, кликаем по главному файлу v2rayN **от имени администратора**. В папке ПКМ и создаём ярлык на рабочем столе, закрепляем на таскбаре для удобства.
2. Запускаем главный файл v2rayN от имени администратора.
3. Язык меняется через <kbd>···</kbd> в правом верхнем углу.

<div align="center">
  <img src="https://s1.hostingkartinok.com/uploads/images/2026/03/a62bc6eef86e4589b11b1c7af859b184.jpg" width="300">
</div>

4. Внизу выбираем <kbd>Global</kbd> и <kbd>Установить системный прокси</kbd>.

<div align="center">
  <img src="https://s1.hostingkartinok.com/uploads/images/2026/03/fefa006ecb2f2a81437ffa0fe9269bb1.jpg" width="500">
</div>

5. Чтобы вставить ссылку — переходим в раздел <kbd>Серверы</kbd> → <kbd>Импорт по URL</kbd>. После этого сверху появляется окно **import_sub** рядом с **Все серверы** — переключаемся на него. Сверху нажимаем <kbd>Группа подписки</kbd> → <kbd>Обновить подписку с прокси</kbd>.

<div align="center">
  <img src="https://s1.hostingkartinok.com/uploads/images/2026/03/8e4fcaa1ada2ab986acb3f4ef1260a12.jpg" width="300">
</div>

6. Дважды кликаем по нужному серверу → <kbd>Подтвердить</kbd>. VPN подключён и уже работает.

> [!CAUTION]
> Выключать VPN — не просто закрыть окно. Нужно открыть скрытые иконки в трее, нажать на v2rayN и выбрать <kbd>Выход</kbd>.

<div align="center">
  <img src="https://s1.hostingkartinok.com/uploads/images/2026/03/0d8043654774ea06b2a9115687099216.jpg" width="400">
</div>

В дальнейшем VPN включается автоматически при каждом запуске приложения.

Кнопка <kbd>Режим VPN</kbd> / <kbd>VPN tun</kbd> — это не включение VPN. Эта кнопка активирует режим туннелирования — нужна только если какие-то сайты или приложения не работают через обычный прокси. Я рекомендую всегда её включать.

### 2.1. Продвинутые настройки

Для улучшения скорости и работы VPN нужно перейти сверху в раздел <kbd>Настройки</kbd> → <kbd>Настройка параметров</kbd>:

- <kbd>Настройки TunMode</kbd> → включить поддержку IPv6.

  > Даже если ваш **домашний** провайдер не поддерживает IPv6 — это нужно для другого.

- <kbd>Ядро: базовые настройки</kbd> → включаем поддержку **QUIC**.
- <kbd>Настройки v2rayN</kbd>: включить автозапуск (при включении ПК); включить протокол безопасности TLS v1.3; включить аппаратное ускорение.

### 2.2. Примечания для пользователей Linux / macOS

**Linux:**

Перед запуском приложения нужно поставить корректную версию ядра **sing-box** ([v1.10.7](https://github.com/SagerNet/sing-box/releases/tag/v1.10.7)) и обновить **xray** до последней версии ([Xray-core releases](https://github.com/XTLS/Xray-core/releases)). Скачаются архивы с файлами sing-box и xray — их нужно переместить в папки:

```
v2rayN/bin/sing-box/
v2rayN/bin/xray/
```

> Неизвестно, есть ли эта проблема на macOS — если возникает, пожалуйста, напишите мне.

**macOS:**

При открытии файла v2rayN есть проблема — нужно открыть командную строку и написать:

```bash
xattr -cr путь-до-папки-v2rayN
```

После этого предупреждение исчезнет.
