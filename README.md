## 0. Общие сведения

Ранее вам была прислана ссылка короткого формата. Её не нужно открывать в браузере. Нужно скопировать и вставить её в одно из клиентских приложений с поддержкой **XRay-core**, указанных в статье ниже.

> [!TIP]
> Если у вас возникают проблемы с установкой приложений из-за блокировок — я могу выслать файлы по почте. Напишите мне в личных сообщениях операционные системы и адрес вашей почты.

После импорта появятся два немецких сервера:

| Сервер | Описание | Когда использовать |
|--------|----------|--------------------|
| **Whitelist** | Обходит белые списки, работает медленнее | Только при необходимости |
| **Main** | Без обхода списков, быстрее и стабильнее | Основной, особенно при кабельном интернете |

## 1. Мобильные устройства (Android / iOS)

- **Android** — скачиваем [**v2RayTun**](https://play.google.com/store/apps/details?id=com.v2raytun.android&hl=en&pli=1) в Google Play, нажимаем <kbd>+</kbd> и импортируем ссылку из буфера обмена.
- **iOS** — скачиваем [**v2Box**](https://apps.apple.com/us/app/v2box-v2ray-client/id6446814690) в App Store (с v2RayTun на iOS есть проблемы).

> [!CAUTION]
> Начиная с [28 марта 2026 года](https://www.currenttime.tv/a/apple-po-trebovaniyu-roskomnadzora-udalila-neskolko-vpn-klientov-iz-rossiyskogo-app-store/33718658.html) в **App Store** данные приложения можно скачать **только** при смене региона или [Apple ID](https://www.iphones.ru/iNotes/kak-sozdat-zagranichnyy-apple-id-bez-bankovskoy-karty-s-rossiyskim-nomerom-telefona-samyy-aktualnyy-sposob-v-2024-godu-04-13-2024) на нероссийский.

> [!WARNING]
> Не рекомендую использовать приложение **Happ** ни на одном из устройств — оно очень нестабильно. Если вы пользовались им ранее, замените его на одно из списка выше.

## 2. ПК (Windows / Linux / macOS)

Скачиваем **v2rayN** версии 7.7.0 с GitHub: [releases/tag/7.7.0](https://github.com/2dust/v2rayN/releases/tag/7.7.0) — выбираем `.zip` файл под свою OS. Обновляться до новых версий не рекомендуется.

> [!NOTE]
> Если у вас Linux или macOS, обязательно посмотрите [п. 2.2](#22-примечания-для-пользователей-linux--macos).

**Шаги установки:**

1. Распаковываем архив, запускаем главный файл v2rayN **от имени администратора**.
   Создаём ярлык на рабочем столе для удобства.
2. Язык меняется через <kbd>⋯</kbd> в правом верхнем углу.

<div align="center">
  <img src="https://s1.hostingkartinok.com/uploads/images/2026/03/a62bc6eef86e4589b11b1c7af859b184.jpg" width="600">
</div>

3. Внизу выбираем <kbd>Global</kbd> → <kbd>Установить системный прокси</kbd>.

<div align="center">
  <img src="https://s1.hostingkartinok.com/uploads/images/2026/03/fefa006ecb2f2a81437ffa0fe9269bb1.jpg" width="600">
</div>

4. Переходим в <kbd>Серверы</kbd> → <kbd>Импорт по URL</kbd>.
   После этого сверху появится вкладка **import_sub** — переключаемся на неё.
5. Нажимаем <kbd>Группа подписки</kbd> → <kbd>Обновить подписку с прокси</kbd>.

<div align="center">
  <img src="https://s1.hostingkartinok.com/uploads/images/2026/03/8e4fcaa1ada2ab986acb3f4ef1260a12.jpg" width="600">
</div>

6. Дважды кликаем по нужному серверу → <kbd>Подтвердить</kbd>. VPN подключён.

> [!CAUTION]
> **Выключать VPN — не просто закрыть окно!**
> Нужно открыть скрытые иконки в трее, нажать на v2rayN и выбрать <kbd>Выход</kbd>.

<div align="center">
  <img src="https://s1.hostingkartinok.com/uploads/images/2026/03/0d8043654774ea06b2a9115687099216.jpg" width="600">
</div>

В дальнейшем VPN включается автоматически при каждом запуске приложения.

> [!NOTE]
> Кнопка <kbd>Режим VPN</kbd> / <kbd>VPN tun</kbd> — это не включение VPN, а режим туннелирования.
> Нужна только если какие-то сайты или приложения не работают через обычный прокси. Рекомендую всегда её включать.

### 2.1. Продвинутые настройки

<details>
<summary>Развернуть настройки</summary>

Переходим в <kbd>Настройки</kbd> → <kbd>Настройка параметров</kbd>:

- **Настройки TunMode** → включить поддержку IPv6.

> [!NOTE]
> Даже если ваш домашний провайдер не поддерживает IPv6 — это нужно для другого.

- **Ядро: базовые настройки** → включить поддержку **QUIC**.
- **Настройки v2rayN**:
  - ✅ Включить автозапуск при включении ПК
  - ✅ Включить протокол безопасности TLS v1.3
  - ✅ Включить аппаратное ускорение

</details>

### 2.2. Примечания для пользователей Linux / macOS

<details>
<summary>Развернуть примечания</summary>

**Linux:**

Перед запуском нужно установить корректную версию ядра **sing-box**
([v1.10.7](https://github.com/SagerNet/sing-box/releases/tag/v1.10.7))
и обновить **xray** до последней версии
([Xray-core releases](https://github.com/XTLS/Xray-core/releases)).

Скачанные файлы перемещаем в папки:
```
v2rayN/bin/sing-box/
v2rayN/bin/xray/
```

**macOS:**

При открытии v2rayN может появиться предупреждение безопасности. Чтобы убрать его, выполните в терминале:

```bash
xattr -cr путь-до-папки-v2rayN
```

> [!NOTE]
> Неизвестно, есть ли проблема с sing-box на macOS. Если возникает — напишите мне.

</details>
